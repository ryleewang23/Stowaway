# Stowaway
Stowaway helps travelers generate personalized packing lists using AI, live weather forecasts, and destination information.

An AI-powered travel packing assistant that creates personalized packing lists based on destination, weather, trip length, and planned activities.

## Features

- 🤖 AI-powered packing suggestions
- 🌤️ Live weather forecasts
- 📍 Destination autocomplete
- 🖼️ Destination photos
- 🕒 Local time and timezone
- 📦 Categorized packing checklist
- 📈 Packing progress tracker
- 🛍️ Amazon shopping links

## Built With

- Python
- Streamlit
- OpenAI API
- Requests
